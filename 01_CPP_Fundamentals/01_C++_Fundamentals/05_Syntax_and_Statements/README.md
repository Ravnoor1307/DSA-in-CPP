
# 05 — Syntax and Statements

## Overview

This folder introduces the rules that govern valid C++ code, including statements, expressions, identifiers, keywords, punctuation, blocks, and scope.

## Files

| File           | Purpose                                                                     |
| -------------- | --------------------------------------------------------------------------- |
| `notes.md`     | Detailed explanation of C++ syntax and statements.                          |
| `examples.cpp` | Working examples of declarations, expressions, output, comments, and scope. |
| `practice.cpp` | Exercises for applying the concepts.                                        |
| `README.md`    | Learning objectives and completion checklist.                               |

## Learning Objectives

After finishing this topic, you should be able to:

* Explain what syntax means.

* Recognize common C++ statements.

* Distinguish expressions from statements.

* Use semicolons and braces correctly.

* Declare variables using valid identifiers.

* Recognize keywords and case sensitivity.

* Write readable, consistently formatted code.

* Identify common syntax errors.

* Understand how blocks affect variable scope.

* Distinguish syntax errors from logical errors.

## Recommended Learning Order

1. Read `notes.md`.

2. Study `examples.cpp`.

3. Compile and run `examples.cpp`.

4. Complete each exercise in `practice.cpp`.

5. Compile the practice file and correct any errors.

6. Answer the review questions in `notes.md` without looking at the answers.

## Compilation Command

```
g++ -std=c++17 -Wall -Wextra -pedantic examples.cpp -o examples
```

Run on Windows PowerShell:

```
.\examples.exe
```

Run on Linux or macOS:

```
./examples
```
