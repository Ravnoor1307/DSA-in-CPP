
<WritingBlock id="73105" variant="document"># VS Code Extensions for C++

## Objective

Install the extensions that help with C++ development.

## 1. Microsoft C/C++ Extension

Extension name: `C/C++`

Publisher: Microsoft

Install it from the VS Code Extensions panel or:

[https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools)

Features include:

* Code completion and IntelliSense.

* Error highlighting.

* Navigation to definitions.

* Debugging support.

* Code browsing.

## 2. CMake Tools — Optional

Extension name: `CMake Tools`

Install this only when you begin working on projects that use CMake. Basic DSA practice does not require it.

## 3. Code Runner — Optional

Code Runner can execute small programs, but it is not required.

For learning DSA, prefer compiling through the terminal. This teaches you the actual compiler commands and makes compiler errors easier to understand.

For interactive programs using `cin`, terminal execution is often more convenient than running through an extension's output panel.

## Verify Your Setup

1. Open a `.cpp` file.

2. Confirm that C++ syntax highlighting works.

3. Check that IntelliSense recognizes standard headers.

4. Compile the program using the terminal.

5. Run the executable.

## Important Note

An extension does not automatically install a working C++ compiler. You must configure GCC/G++ or Clang separately.

## Completion Checklist

* Microsoft C/C++ extension installed.

* C++ syntax highlighting works.

* IntelliSense works.

* Terminal compilation works.</WritingBlock>
