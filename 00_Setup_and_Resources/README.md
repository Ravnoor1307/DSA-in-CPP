# Setup and Resources

## Objective

Prepare a working C++17 development environment for learning Data Structures and Algorithms and preparing for coding interviews.

## Recommended Setup

* Operating system: Windows, Linux, or macOS
* Code editor: Visual Studio Code
* Compiler: GCC/G++
* C++ standard: C++17
* Version control: Git and GitHub

## Setup Checklist

* [ ] Install a C++ compiler.
* [ ] Verify that the compiler works.
* [ ] Install Visual Studio Code.
* [ ] Install the Microsoft C/C++ extension.
* [ ] Configure compilation and execution.
* [ ] Run `compile_and_run.cpp` successfully.
* [ ] Learn basic debugging.
* [ ] Create a GitHub repository for DSA practice.

## Completion Criteria

Setup is complete when you can compile, run, debug, and save a C++17 program successfully.
