#  Variables in C++

## Overview

This folder introduces variables in C++. Variables allow programs to store, access, and modify information while they execute.

You will learn how to declare variables, initialize them, assign new values, choose meaningful names, and understand the difference between a variable's name, type, and value.

## Files in This Folder

| File | Purpose |
|---|---|
| `README.md` | Overview, learning objectives, and instructions |
| `notes.md` | Detailed theory, syntax, examples, and common mistakes |
| `examples.cpp` | Complete working examples of variables |
| `practice.cpp` | Exercises for applying the concepts |

## Learning Objectives

After completing this topic, you should be able to:

- Explain what a variable is and why it is needed.
- Declare and initialize variables.
- Assign new values to existing variables.
- Understand basic variable naming rules.
- Use meaningful variable names.
- Identify common variable-related errors.
- Write small programs that store and display information.

## Recommended Learning Order

1. Read `notes.md` carefully.
2. Run `examples.cpp` and compare the output with the code.
3. Complete the exercises in `practice.cpp`.
4. Compile and run your solutions.
5. Review the common mistakes in the notes.

## Compilation Instructions

Use a C++17-compatible compiler such as GCC.

### Compile

```bash
g++ -std=c++17 -Wall -Wextra -pedantic examples.cpp -o examples
```

### Run on Windows PowerShell

```powershell
.\examples.exe
```

### Run on Linux/macOS

```bash
./examples
```

To compile the practice file, replace `examples.cpp` and `examples` with `practice.cpp` and `practice`.
