

# Topic 01: What Is C++?

## Objective

Understand what C++ is, where it is used, and how a basic C++ program works.

## Files

* `notes.md` — Detailed theory and revision notes.

* `examples.cpp` — Demonstration programs.

* `practice.cpp` — Exercises to solve independently.

## Prerequisites

* Basic computer usage.

* A text editor.

* A working C++ compiler.

## Learning Checklist

* Understand the definition of C++.

* Identify common applications of C++.

* Understand source code, compilers, and executables.

* Understand the structure of `main()`.

* Compile and execute `examples.cpp`.

* Complete the exercises in `practice.cpp`.

* Answer the revision questions in `notes.md`.

## Completion Rule

Move to the next topic after you can explain the first program and complete the practice exercises independently.
