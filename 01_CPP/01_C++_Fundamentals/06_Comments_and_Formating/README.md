
# 06 — Comments and Formatting

## Overview

This folder teaches you to write readable and maintainable C++ code using useful comments, consistent indentation, descriptive names, spacing, and formatting tools.

## Files

| File           | Purpose                                                            |
| -------------- | ------------------------------------------------------------------ |
| `notes.md`     | Detailed notes on comments, formatting, naming, and documentation. |
| `examples.cpp` | A complete, readable example demonstrating the concepts.           |
| `practice.cpp` | Exercises to improve code readability and consistency.             |
| `README.md`    | Learning objectives and progress checklist.                        |

## Learning Objectives

By completing this topic, you should be able to:

* Write single-line and block comments.

* Decide when comments are useful.

* Recognize unnecessary or outdated comments.

* Apply consistent indentation and brace placement.

* Use meaningful variable and function names.

* Improve spacing and line breaks.

* Organize code into readable sections.

* Understand documentation comments.

* Recognize the role of automated formatting tools such as ClangFormat.

## Recommended Learning Order

1. Read `notes.md`.

2. Study `examples.cpp`.

3. Compile and run the example.

4. Complete the formatting exercises in `practice.cpp`.

5. Compare your updated code with the recommended style.

6. Compile and run the updated program.

## Compilation Command

```
g++ -std=c++17 -Wall -Wextra -pedantic examples.cpp -o examples
```

Run on Windows PowerShell:

```
.\examples.exe
```

Run on Linux or macOS:

```
./examples
```

## Completion Checklist

* I can write single-line and block comments.

* I understand when comments add value.

* I can indent nested blocks consistently.

* I use spaces around operators.

* I use meaningful variable and function names.

* I can organize a program using blank lines.

* I can recognize outdated or unnecessary comments.

* I understand the purpose of documentation comments.

* I understand what an automated formatter does.

* I completed the practice exercises.
