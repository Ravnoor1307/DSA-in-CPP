

# Topic 02: History and Features of C++

## Objective

Learn how C++ developed, understand its major standard versions, and identify the language features that make it useful.

## Files

* `notes.md` — History, features, comparisons, and revision questions.

* `examples.cpp` — Programs demonstrating C++ data types, strings, and standard library algorithms.

## Prerequisites

* Basic understanding of what C++ is.

* Familiarity with the structure of a simple C++ program.

* A working C++ compiler.

## Topics Covered

1. The history of C and C++.

2. Bjarne Stroustrup and C with Classes.

3. The naming of C++.

4. Major C++ standard versions.

5. Procedural programming.

6. Object-oriented programming.

7. Generic programming.

8. The C++ standard library.

9. Performance and memory management.

10. Advantages and limitations of C++.

11. Differences between C and C++.

## How to Practice

1. Read `notes.md`.

2. Compile and run `examples.cpp`.

3. Explain each example in your own words.

4. Modify the vector values and observe how sorting works.

5. Answer the revision questions without looking at the notes.

## Completion Criteria

* Explain the origins of C++.

* Recall the important standardization milestones.

* Describe at least five C++ features.

* Explain the difference between C and C++.

* Run the example program successfully.

* Complete the revision questions.
