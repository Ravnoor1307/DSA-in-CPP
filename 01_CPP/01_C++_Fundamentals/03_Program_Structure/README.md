

# Topic 03: C++ Program Structure

## Objective

Understand the basic structure of a C++ program and learn how headers, functions, statements, braces, variables, output operations, and return statements work together.

## Files

* `notes.md` — Detailed explanations, examples, common mistakes, and revision questions.

* `hello_world.cpp` — A minimal working C++ program.

* `program_breakdown.cpp` — A complete program demonstrating fundamental structural components.

## Prerequisites

* Basic understanding of C++.

* Familiarity with source files and compilation.

* A working C++ compiler.

## Topics Covered

1. Components of a C++ program.

2. Preprocessor directives.

3. Header files.

4. The `main()` function.

5. Curly braces and code blocks.

6. Statements and declarations.

7. Variables.

8. Output using `std::cout`.

9. Return statements.

10. Comments and formatting.

11. Common syntax mistakes.

## How to Practice

1. Read `notes.md` carefully.

2. Compile and run `hello_world.cpp`.

3. Study `program_breakdown.cpp` line by line.

4. Change the integer values and predict the output.

5. Remove a semicolon or brace temporarily to observe a compiler error, then correct it.

6. Answer the revision questions without copying from the notes.

## Completion Checklist

* Explain the structure of a basic C++ program.

* Understand the purpose of header files.

* Explain the role of `main()`.

* Use statements, braces, and semicolons correctly.

* Print output using `std::cout`.

* Compile and execute both `.cpp` files.

* Complete the revision questions.
